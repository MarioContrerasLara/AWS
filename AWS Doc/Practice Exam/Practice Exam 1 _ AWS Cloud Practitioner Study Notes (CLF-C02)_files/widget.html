A. IAM roles.
B. IAM users.
C. IAM user groups.
D. AWS Organizations. (the correct answer is D Not C : AWS Organizations is the best solution for this scenario. Create and manage accounts: Organize accounts by teams or departments.
Apply policies: Use Service Control Policies (SCPs) to centrally manage permissions and control which AWS services are accessible to each account or group of accounts.
Automate account management: Automatically apply settings to new accounts and enforce consistent security policies across your organization.)
